Connection and privacy

Proxy
Send all of ZIMaker's downloads through a proxy, such as Tor, Psiphon or another proxy you trust. With one set, ZIMaker never connects directly: if the proxy isn't running, downloads fail instead of going around it. A VPN running on your computer needs no setting here.
Psiphon shows its SOCKS port in its settings (you can set a fixed one there).
Programs on Windows (Tor Browser, Psiphon, I2P, Hyphanet) listen on Windows' own address (127.0.0.1), which ZIMaker can't reach in WSL's default network mode. To fix this once (Windows 11 22H2 or newer): in your Windows user folder (C:\Users\you), create a text file named .wslconfig containing the two lines [wsl2] and networkingMode=mirrored, then run wsl --shutdown in PowerShell (this stops all Linux programs in WSL) and open ZIMaker again. Or run the proxy inside WSL instead: Tor's service (sudo apt install tor) listens on 127.0.0.1:9050.
ZIMaker is running in a Docker container, where 127.0.0.1 is the container itself, not your computer. For a program running on your computer (Tor Browser, Psiphon, an I2P router), use the address host.docker.internal instead, and set that program to accept connections from Docker, not only from 127.0.0.1. Hyphanet and your own IPFS program are only read at 127.0.0.1: for those, run the container on the computer's own network (Linux only; see “Docker” in the README).

    ZIMaker

    Turn websites, archive.org books, ebooks, documents and pictures into ZIM files for Kiwix.

    1. What to convert

      Drag files, or links from your browser, anywhere onto this window — or
      Which files work?
      • Ebooks: EPUB, MOBI, AZW, AZW3, FB2
      • Documents: Word (DOCX), OpenDocument (ODT), RTF, PowerPoint (PPTX), Excel (XLSX), CSV, Markdown, plain text, HTML, Jupyter notebooks, LaTeX, and more
      • Older office files*: DOC, XLS, PPT, ODP, ODS, ODG, WordPerfect, Publisher, Visio
      • Page-based: PDF, XPS, CBZ comics
      • Saved web pages: MHTML / MHT (your browser's “Save as → single file”; handy for sites that block downloads)
      • Emails: EML messages and MBOX mailboxes
      • Pictures: JPG, PNG, GIF, WEBP, HEIC (iPhone), AVIF, TIFF, BMP, SVG, PSD and more (all pictures in one job become one gallery)
      • Audio and video*: MP4, MKV, MOV, AVI, WebM, WMV, MP3, M4A, WAV, FLAC, OGG and more, with .srt / .vtt subtitles
      • Archives: ZIP, TAR (.tar.gz …), and 7Z, RAR, CBR/CB7 comics, CHM help files*: a saved website, a comic, or each file inside converted
      • ZIM files: preview, edit a copy, or combine several into one, in Your ZIM files below (drop a .zim onto the window to add it there)
      • * needs an optional tool — see ⚙ Settings → Optional tools
      • Not supported: DjVu, Apple iWork files (export them first), streaming sites like YouTube
